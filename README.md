### Вариант 1

Оператор Собеля — дискретный дифференциальный оператор, который вычисляет приближённое значение градиента яркости изображения. Назван в честь Ирвина Собеля и Гэри Фельдмана.

Результат применения оператора Собеля в каждой точке изображения — либо вектор градиента яркости в этой точке, либо его норма.
